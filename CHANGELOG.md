# Changelog

## v1.0.0 — Nieuwe repository, zelfde code

De repository is opnieuw begonnen. De code van 1.0.0 is byte voor byte
die van v4.12 uit de oude reeks; er verandert niets aan wat er draait.
De geleerde data staat in `.storage/` van Home Assistant en wordt hier
niet door geraakt.

Wat er uit de repository is gehaald: 156 dubbele toetsbestanden in de
root (kopieën van `tests/`, waarvan 30 verouderd), twee losse
overdrachtsdocumenten, een leeg toetsbestand en vier dashboardbijlagen
die nergens meer werden genoemd.

Wat er is gebleven: de integratiemap (22 bestanden), 347 toetsen, het
dashboard, de svg-referentie, de ontwikkeldocumentatie en de volledige
geschiedenis van de oude reeks in `docs/GESCHIEDENIS.md`. De
verwijzingen in de code naar oude versienummers slaan daarop.

Nummering vanaf hier: `1.0.1` voor een reparatie, `1.1.0` voor nieuw
werk.

**Volledige testsuite**: 3789 tests, allemaal groen.
